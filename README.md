# Studio Routine

A phone home-screen app for a flameworking studio day: open and close checklists (gas lines, kiln, bench), the torch priority order, a week plan, and a dinner-by-5:30 plan. Checkboxes reset each morning and save on the device. Works offline once installed.

## Install on your phone
1. Open the GitHub Pages link in Safari (iPhone) or Chrome (Android).
2. Tap Share → **Add to Home Screen** (iPhone) or the menu → **Add to Home screen** (Android).

## Run it
Static files, no build. Enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main`, root).
